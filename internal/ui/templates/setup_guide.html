PAT Tokens & Webhook Setup

Create the GitHub personal access tokens for your source and target repositories, then add the webhook that lets the mirror react to push events.

Create the Source Token

Use the source token to let GitHub Mirror read the repository you want to mirror from.

  1. Open GitHub and click your profile photo.
  2. Go to Settings.
  3. Open Developer settings.
  4. Open Personal access tokens.
  5. Create a new token.
  6. Grant read access to the source repository contents.
  7. Copy the token and store it somewhere safe.

Use this token in the Source Token (PAT) field.

Create the Target Token

Use the target token to let GitHub Mirror push updates to the destination repository.

  1. Open GitHub and click your profile photo.
  2. Go to Settings.
  3. Open Developer settings.
  4. Open Personal access tokens.
  5. Create a new token.
  6. Grant write access to the target repository contents.
  7. Copy the token and store it somewhere safe.

Use this token in the Target Token (PAT) field.

Recommended Token Access

Use separate tokens when possible.

  • Source token: read repository contents
  • Target token: read and write repository contents

GitHub only shows the full token once, and organization-owned repositories may require token approval before use.

Create the Mirror First

Before you can add the webhook, create the mirror configuration in this app with:

  • A mirror name
  • The source repository URL
  • The target repository URL
  • The source token
  • The target token

After the mirror is created, open its detail page to see the webhook payload URL.

Add the Webhook on GitHub

Configure the webhook on the source repository so GitHub Mirror can react to pushes automatically.

  1. Open the source repository on GitHub.
  2. Go to Settings.
  3. Open Webhooks.
  4. Click Add webhook.
  5. Paste the Payload URL shown on the mirror detail page.
  6. Set Content type to application/json.
  7. Enter the webhook secret if your setup requires one.
  8. Choose the Push event.
  9. Save the webhook.

Add this webhook to the source repository, not the target repository.

Verify the Setup

After saving the webhook:

  • Return to the mirror detail page
  • Use Test Tokens to confirm credentials still work
  • Use Sync Now to trigger a manual sync
  • Review the sync history for success or failure
